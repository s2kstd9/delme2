# 보석 광산

브라우저에서 바로 실행되는 9×9 보석 맞추기(매치-3) 게임입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치할 것은 없습니다.

## 규칙

- 이웃한 보석 두 개를 바꿔 같은 색 3개 이상을 한 줄로, 또는 2×2 사각형으로 맞춥니다.
- 4개 또는 ㄱ·T자 매치 → 불꽃 보석 (주변 3×3 폭발)
- 5개 매치 → 별 보석 (가로·세로 한 줄 전체 제거)
- 보석 색마다 고유한 음이 있고, 연쇄·사각형·특수 보석마다 다른 효과음이 납니다.
- 연쇄 매치는 콤보 배수로 점수가 올라갑니다.
- 더 이상 움직일 수 없으면 게임이 끝납니다.
